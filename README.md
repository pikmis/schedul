# Schedule I — Русский перевод

Полный русификатор игры **Schedule I** (Steam): весь интерфейс, диалоги, квесты и подсказки на русском. Переводы **обновляются автоматически** прямо с этого репозитория — раз заходишь сюда и правишь `TranslaitBROO.txt`, всем игрокам это подхватывается при следующем запуске игры, никакой пересборки мода не нужно.

📦 **[Скачать релиз (ZIP)](https://github.com/pikmis/schedul/releases/latest)**

---

## Установка для новичков (по шагам)

Тут нет ничего сложного — просто иди по пунктам.

### Шаг 1. Найди папку игры

1. Открой **Steam**, в библиотеке кликни на **Schedule I** правой кнопкой мыши.
2. Выбери **Управление → Просмотреть локальные файлы**.
3. Откроется папка игры — в ней лежит `Schedule I.exe`. Всё будем раскладывать сюда.

### Шаг 2. Установи BepInEx (движок модов, один раз)

Моды работают на бесплатной платформе **BepInEx 6**.

1. Перейди на **https://builds.bepinex.dev/projects/bepinex**
2. Открой вкладку **BepInEx 6**, выбери раздел **IL2CPP** (игра на IL2CPP — версии BepInEx 5 или Mono **не подойдут**).
3. Скачай архив **BepInEx_x64** (`.zip`).
4. Открой ZIP и перетащи **всё содержимое в папку игры**, с заменой.

Проверка: рядом с `Schedule I.exe` появились папка `BepInEx`, файлы `doorstop_config.ini` и `winhttp.dll`.

### Шаг 3. Первый запуск

Запусти игру, дождись главного меню, закрой. BepInEx создаст служебные файлы.

### Шаг 4. Установи наш мод

1. Скачай ZIP из **[релизов](https://github.com/pikmis/schedul/releases/latest)** (`schedulei-ru-*.zip`).
2. Открой его и перетащи **всё содержимое в папку игры**, с заменой.
3. Проверка: появилось `BepInEx\plugins\ScheduleIRussian.dll` и файл `TranslaitBROO.txt` рядом с `Schedule I.exe`.

### Шаг 5. Играй

Запусти игру — интерфейс русский. Для надёжности открой `BepInEx\LogOutput.log` блокнотом и найди строку:

```
Russian translation loaded: ... entries
```

Если она есть — установлено правильно.

## Возможности

- Перевод всего текста: интерфейс, диалоги NPC, квесты, подсказки, субтитры
- **Авто-обновление переводов**: при запуске и раз в час мод тянет свежую базу с этого репозитория (при недоступности GitHub — зеркало jsDelivr, затем повтор через 2 минуты); офлайн работает на локальном кэше `BepInEx\config\TranslaitBROO.remote.txt`
- Умные шаблоны для динамического текста: время (`1:00 PM Monday → Понедельник 13:00`), проценты и счётчики (`Pour into pot (42%)`), `5 дней назад` и подобное
- Авто-скан сцены каждые 3 секунды — текст переводится сам, как только появляется

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| **F8** | Оверлей со всем текстом сцены |
| **F9** | Принудительно обновить переводы с GitHub |
| **F10** | Полный скан текстов сцены |
| **F12** | Очистить дамп-файлы (Untranslated / AllDisplayed / AllTexts) |

Настройки (адреса источников, период обновления, авто-скан): `BepInEx\config\schedulei.russian.translation.cfg`

## Как добавить или исправить перевод

1. Открой [`TranslaitBROO.txt`](./TranslaitBROO.txt) (в вебе — кнопка Edit, или локально).
2. Правь по формату (см. ниже), закоммить в `main`.
3. Готово — у игроков обновится при следующем запуске (или сразу по F9).

### Формат файла

- Каждая строка: `оригинал=перевод`, кодировка UTF-8 без BOM.
- Первая строка **обязательна**: `# SCHEDULEI_RU_BASE` — без неё DLL отклонит файл.
- Пустые строки и строки, начинающиеся с `#`, игнорируются.
- Левая часть (ключ) — точная копия английского текста, включая теги `<color=#...>` и плейсхолдеры — её не менять.
- Правая часть — перевод; `\n` = перенос строки.
- Поздние дубли перекрывают ранние: повторяющийся ключ берётся из последней строки.

### Стиль

- Диалоги NPC — живо, можно грубо и с матом, как в игре.
- Интерфейс — коротко и по делу, без мата.
- Ненужные старые строки удалять — мод сам уберёт их из памяти игроков.

## Troubleshooting

| Проблема | Решение |
|---|---|
| Текст остался английским | Проверь `BepInEx\LogOutput.log`: есть ли `Loading [Schedule I Russian Translation]`. Нет — BepInEx не там или установлена не **IL2CPP**-версия. |
| В логе `Error loading [Schedule I Russian Translation]` | Скопируй текст ошибки и создай [issue](https://github.com/pikmis/schedul/issues). |
| Игра не запускается | Удали из папки игры `BepInEx`, `doorstop_config.ini`, `winhttp.dll` — всё вернётся как раньше. Повтори Шаг 2 (нужен именно BepInEx 6 **IL2CPP x64**). |
| Часть текста осталась английской | Подожди 3 секунды (авто-скан) или нажми **F10**. Не помогло — создай issue с точным текстом этой строки. |

## Разработчикам

- Исходник мода: `TranslationMod.Source.cs` (патчи `TMP_Text.set_text`/`SetText`, дамперы, авто-обновление), проект: `TranslationMod.csproj` (.NET 6).
- Сборка: `dotnet build TranslationMod.csproj`, результат → `BepInEx/plugins/ScheduleIRussian.dll`.
- Непереведённый текст из игры пишется в `Untranslated.txt` рядом с игрой (или через F10/F8) — это очередь на перевод.
