# Schedule I — Русский перевод

Полный русификатор игры **Schedule I** (Steam): весь интерфейс, диалоги, квесты и подсказки на русском. Переводы **обновляются автоматически** прямо с этого репозитория — правишь `TranslaitBROO.txt`, всем игрокам это подхватывается при следующем запуске игры, никакой пересборки мода не нужно.

📦 **[Скачать релиз (ZIP)](https://github.com/pikmis/schedulerus/releases/latest)** — в архиве **всё уже внутри**: и мод, и BepInEx (движок модов), и переводы.

---

## Установка (2 шага)

Никаких дополнительных программ и загрузок не нужно — только этот ZIP.

### Шаг 1. Найди папку игры

1. Открой **Steam**, в библиотеке кликни на **Schedule I** правой кнопкой мыши.
2. Выбери **Управление → Просмотреть локальные файлы**.
3. Откроется папка — в ней лежит `Schedule I.exe`. Сюда.

### Шаг 2. Распакуй ZIP в папку игры

1. Открой скачанный ZIP.
2. **Выдели всё внутри** (Ctrl+A) и перетащи в папку игры, подтверди замену.

Готово — запускай игру через Steam.

> **Уже стоит свой BepInEx 6 (IL2CPP)?** Можно не качать весь ZIP: в релизе есть отдельный `ScheduleIRussian.dll` — кинь его в `BepInEx\plugins`, а [`TranslaitBROO.txt`](./TranslaitBROO.txt) — в папку игры. База и так умеет докачиваться с GitHub сама, но локальный файл гарантирует мгновенный перевод и работу без интернета.

> **Первый запусок:** может мелькнуть чёрное окно BepInEx и игра откроется дольше (1–3 минуты) — генерируются служебные файлы. Происходит только один раз.

### Проверка

Интерфейс стал русским — всё работает. Для надёжности открой `BepInEx\LogOutput.log` блокотом и найди строку:

```
Russian translation loaded: ... entries
```

Если у тебя уже стоял BepInEx — он просто обновится, чужие моды и настройки не удаляются (распаковка ничего не удаляет).

## Возможности

- Перевод всего текста: интерфейс, диалоги NPC, квесты, подсказки, субтитры
- **Авто-обновление переводов**: при запуске и раз в час мод тянет свежую базу с этого репозитория (при недоступности GitHub — зеркало jsDelivr, затем повтор через 2 минуты); офлайн работает на локальном кэше `BepInEx\config\TranslaitBROO.remote.txt`
- Умные шаблоны для динамического текста: время (`1:00 PM Monday → Понедельник 13:00`), проценты и счётчики (`Pour into pot (42%)`), `5 дней назад` и подобное
- Скан сцены после каждой загрузки уровня и раз в 30 секунд — текст переводится сам, без просадок FPS

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| **F10** | Принудительно обновить перевод: полный скан всех текстов — если что-то вдруг осталось английским |

Настройки (адреса источников, период обновления, авто-скан): `BepInEx\config\schedulei.russian.translation.cfg`

## Как добавить или исправить перевод

1. Открой [`TranslaitBROO.txt`](./TranslaitBROO.txt) (в вебе — кнопка Edit, или локально).
2. Правь по формату (см. ниже), закоммить в `main`.
3. Готово — у игроков обновится при следующем запуске (или сразу по F10 в игре).

### Формат файла

- Каждая строка: `оригинал=перевод`, кодировка UTF-8 без BOM.
- Первая строка **обязательна**: `# SCHEDULEI_RU_BASE` — без неё DLL отклонит файл.
- Пустые строки и строки, начинающиеся с `#`, игнорируются.
- Левая часть (ключ) — точная копия английского текста, включая теги `<color=#...>` и плейсхолдеры — её не менять.
- Правая часть — перевод; `\n` = перенос строки.
- Поздние дубли перекрывают ранние: повторяющийся ключ берётся из последней строки.

### Стиль

- Диалоги NPC — живо, можно грубо и с матом, как в игре.
- Интерфейс — коротко и по делу, без мата.
- Ненужные старые строки удалять — мод сам уберёт их из памяти игроков.

## Troubleshooting

| Проблема | Решение |
|---|---|
| Текст остался английским | Нажми **F10** — мод просканирует всё и переведёт. Всё ещё по-английски → в `BepInEx\LogOutput.log` должна быть строка `Loading [Schedule I Russian Translation]`. Нет её — распакуй архив заново, точно в папку с `Schedule I.exe`. |
| В логе `Error loading [Schedule I Russian Translation]` | Скопируй текст ошибки и создай [issue](https://github.com/pikmis/schedulerus/issues). |
| Игра не запускается | Удали из папки игры `BepInEx`, `dotnet`, `doorstop_config.ini`, `winhttp.dll` — игра вернётся в исходное состояние. Дальше — issue с `BepInEx\LogOutput.log`. |
| Чёрное окно висит при первом запуске | Норма, генерация служебных файлов: до 3 минут, только при первом запуске. |
| Часть текста осталась английской | Создай issue с точным текстом этой строки. |

## Разработчикам

- Исходник мода: `TranslationMod.Source.cs` (патчи `TMP_Text.set_text`/`SetText`, дамперы, авто-обновление), проект: `TranslationMod.csproj` (.NET 6).
- Сборка: `dotnet build TranslationMod.csproj`, результат → `BepInEx/plugins/ScheduleIRussian.dll`.
- Непереведённый текст из игры пишется в `Untranslated.txt` рядом с игрой (или через F10) — это очередь на перевод.
- Лицензия кода: [MIT](./LICENSE). Перевод — фанатский, неофициальный.
