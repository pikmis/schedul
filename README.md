# Schedule I — Русский перевод

Полный русификатор игры **Schedule I** (Steam) на базе BepInEx: перевод всего текста интерфейса, диалогов и сцен, с **автоматическим обновлением переводов прямо с этого репозитория** — без пересборки и перевыпуска DLL.

📦 **[Скачать релиз](https://github.com/pikmis/schedul/releases/latest)**

## Возможности

- Переводит весь текст игры на русский (интерфейс, диалоги, подсказки, субтитры, квесты)
- **Авто-обновление**: при запуске и раз в час мод подтягивает свежую базу переводов с GitHub, при неудаче — с зеркала jsDelivr; офлайн работает на локальном кэше
- Умные шаблоны для динамического текста: время (`1:00 PM → 13:00`), дни недели, проценты/счётчики, «5 дней назад» и т.п.
- Авто-скан сцены каждые 3 секунды — текст переводится, как только появляется, без ручных действий
- В комплекте — мод утилит: полёт, телепорт, деньги

## Установка

1. Установи **[BepInEx 6 IL2CPP](https://builds.bepinex.dev/projects/bepinex)** (x64, проверено на nightly **be.788**): распакуй архив в папку игры (там, где `Schedule I.exe`), запусти игру один раз, чтобы сгенерировались папки, затем закрой.
2. Скачай ZIP из **[релизов](https://github.com/pikmis/schedul/releases/latest)** и распакуй **прямо в папку игры**, с заменой файлов.
3. Запусти игру. В `BepInEx/LogOutput.log` должно быть `Russian translation loaded: ... entries`.

В ZIP:
```
BepInEx/plugins/ScheduleIRussian.dll   — русский перевод
BepInEx/plugins/ScheduleIUtilities.dll — утилиты (F6/F7/F4)
TranslaitBROO.txt                      — локальная база переводов (офлайн-фолбэк)
README.md                              — инструкция
```

## Горячие клавиши

**Перевод:**

| Клавиша | Действие |
|---|---|
| F8 | Оверлей со всем текстом сцены |
| F9 | Принудительно обновить переводы с GitHub |
| F10 | Полный скан текстов сцены |
| F12 | Очистить дамп-файлы (Untranslated / AllDisplayed / AllTexts) |

**Утилиты:**

| Клавиша | Действие |
|---|---|
| F6 | Полёт (WASD, Space — вверх, Ctrl — вниз, Shift — ускорение) |
| F7 | Телепорт на 12 метров вперёд |
| F4 | +$10 000 |

## Как обновляются переводы

Мод при каждом запуске (и далее каждый час) скачивает файл `TranslaitBROO.txt` из этого репозитория и применяет его поверх локальной базы. То есть:

- правки в `TranslaitBROO.txt` на ветке `main` **доходят до всех игроков автоматически** — никакой пересборки DLL не нужно;
- изменения, наоборот, удаляющие перевод, тоже применяются (устаревшие ключи не залипают);
- последняя удачная загрузка кэшируется в `BepInEx/config/TranslaitBROO.remote.txt`, поэтому без интернета игра продолжает работать;
- если GitHub недоступен — используется зеркало jsDelivr, затем повтор через 2 минуты.

Конфиг (URL-ы, интервал проверки, авто-скан): `BepInEx/config/schedulei.russian.translation.cfg`.

## Как добавить или исправить перевод

1. Открой [`TranslaitBROO.txt`](./TranslaitBROO.txt) (в вебе — кнопка Edit, или локально).
2. Правь файл по формату (см. ниже) и закоммить в `main`.
3. Через несколько секунд обновится у всех игроков при следующем запуске игры.

### Формат файла

- Каждая строка: `оригинал=перевод`, кодировка UTF-8 без BOM.
- Первая строка **обязательна**: `# SCHEDULEI_RU_BASE` — без неё DLL отклонит файл как мусор.
- Пустые строки и строки, начинающиеся с `#`, игнорируются.
- Левая часть (ключ) — точная копия английского текста, включая теги вида `<color=#...>` и плейсхолдеры — её менять нельзя.
- Правая часть — перевод. `\n` означает перенос строки.
- Поздние дубли перекрывают ранние: если ключ повторяется, действует последняя строка.

### Стиль

- Диалоги NPC — живо, можно грубо и с матом, как в игре.
- Интерфейс — коротко и по делу, без мата.
- Старые/ненужные строки удалять (мод сам уберёт их из памяти игроков).

## Разработчикам

- Непереведённый текст из игры попадает в `Untranslated.txt` рядом с игрой (или через F10/F8) — это список того, что нужно добавить в базу.
- Исходники мода: `TranslationMod.Source.cs` (перевод), `ScheduleIUtilities.Source.cs` (утилиты); сборка — `dotnet build TranslationMod.csproj` / `ScheduleIUtilities.csproj` под .NET 6, затем копия DLL в `BepInEx/plugins`.
